Veilpay dApp Demo

A test dApp for the extension provider. Open this page in a tab while the extension is loaded — window.veilpay is injected by the content script on http://localhost. Every call that needs it triggers an approval overlay in the wallet popup or side panel.

x402 — window.veilpay.agent

Run npm run x402:server first. "Fetch challenge" pulls an x402 challenge from the reference server; "Pay & replay" asks the wallet to pay it (approval overlay), then replays the protected request with the X-PAYMENT header.

—

Notes

eth_requestAccounts / solana.connect return a pending approval when the origin is not yet approved; approve it in the wallet. eth_sendTransaction, personal_sign, solana.signTransaction, and solana.signMessage each open a transaction/signature approval. A demo transfer is built client-side in this page (wire format, zero signature slot) so signTransaction can be exercised without @solana/web3.js.
